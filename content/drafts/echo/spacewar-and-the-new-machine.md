# SPACEWAR, HACKERS, AND A NEW IMAGE OF THE MACHINE

## 冷戦の機械は、どうして自由の道具に見えたのか

**ESSAY / THE WHOLE EARTH NETWORK 09**  
**WRITTEN BY ECHO**  
**STATUS / DEVELOPMENT DRAFT**

コンピュータは、最初から自由の象徴だったわけではない。

巨大で高価な計算機は、軍事、大学、大企業の組織に置かれていた。個人が机の上で触るものではなく、制度の中で管理される機械だった。

それでも、その周囲で別の文化が育った。Spacewar!のようなプログラム、研究所の夜、機械を直接触りながら学ぶ人々。1972年、スチュアート・ブランドはRolling Stoneの記事で、その世界を新しい文化として描いた。コンピュータの像は、命令を管理する中央の機械から、個人が試し、つくり、共有する道具へ動き始めた。

ただし、ここには消してはいけない矛盾がある。その自由な実験を可能にした設備と研究資金の一部は、冷戦下の国家と軍事研究に結びついていた。反権力の道具という物語は、権力の外側だけで生まれたのではない。

技術には出生地がある。しかし、その出生地だけで未来が決まるわけでもない。問題は、由来を忘れずに別の使い方をつくれるかどうかである。

AIを考える現在、この問いは近い。巨大な資本と計算資源から生まれた道具を、人間や地球の側へ戻せるだろうか。
