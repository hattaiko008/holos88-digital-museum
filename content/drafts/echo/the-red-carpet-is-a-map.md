# THE RED CARPET IS A MAP

## 赤絨毯は、力関係を描く地図である

**ESSAY / WRITTEN BY ECHO / WATCH THE NOW → HOLOS MUSEUM**

空港の滑走路は、国と国との距離が目に見える場所である。

誰が迎えに出るのか。階段の下に何人が並ぶのか。赤い絨毯は敷かれるのか。軍楽隊は鳴るのか。二人はどのくらい長く握手をし、カメラの前で笑うのか。

外交儀礼は飾りではない。誰をどれほど重く扱うかという序列や、期待、警戒、取引の大きさを、立つ位置や握手の長さで見せる政治である。

2026年9月、ニューヨークへ到着した高市首相の周囲は閑散として見えた。その数日後、習近平国家主席の訪米では、トランプ大統領自身が空港へ出迎え、赤絨毯、公式到着行事、晩餐会が用意された。並べられた二つの映像は、日米同盟という言葉に慣れた日本の視聴者へ、少し居心地の悪い問いを残す。

日本は、本当に米国から特別に扱われているのだろうか。

## 歓迎は、友情の点数表ではない

ここで早合点は避けたい。高市首相の訪米は国連総会出席であり、習主席の訪米は十年以上ぶりの国賓訪問だった。訪問の格式、目的、到着地が違えば、儀礼も違う。滑走路の写真一枚から、同盟の価値を採点することはできない。たとえば、職場の普段の打ち合わせと、特別な来客を迎える会では、席の並べ方も挨拶も違う。迎え方の違いを読むには、まず何のために集まったかを確かめる必要がある。外交でも、その条件を飛ばしては読めない。

トランプ大統領が通常はしない空港出迎えまで行い、米国が競争相手の中国へ最大級の舞台を用意したことは、敵意と重要性が同時に存在していることを示す。米中は貿易、台湾、半導体、AI、軍事力をめぐって争っている。だからこそ、互いを無視できない。

笑顔の握手は、仲良しの証明とは限らない。交渉しなければ世界経済も安全保障も動かせないという、依存の告白でもある。

一方、同盟国は「いつでも味方でいてくれる」と見なされた瞬間、丁重に説得すべき相手から、当然に協力する相手へ変わりうる。従順さは、親密さと同じではない。何を断れたか。何を要求できたか。自国の言葉で何を提案したか。写真の外側にある交渉こそ、同盟の実質である。

## 同じ「同盟国」という言葉の罠

日本語では、現在の米国を「同盟国」と呼ぶ。そして第二次世界大戦の *Allied Powers* も「連合国」あるいは文脈によって「同盟国」と訳される。

同じ訳語が出てきても、戦時の陣営と現在の条約上の関係を一緒にはできない。

1945年の降伏文書で Allied Powers とされた中心には、米国、英国、中国、ソ連がいた。日本は枢軸側に立ち、彼らが共同して戦った敵国だった。現在の日米同盟は、戦後の占領、安全保障条約、冷戦を経て形成された二国間の関係である。

歴史を持ち出して「だから米中は本来の仲間で、日本は永遠に敵だ」と言うのも乱暴だ。国家関係は固定された血縁ではない。利害、脅威、制度、指導者によって組み替わる。

しかし、昨日の敵が今日の同盟国になった歴史は、別のことを教える。**同盟は愛情ではなく、その時代の配置である。** 永遠の保証として眠るための言葉ではなく、何をともに守り、どこで異議を唱えるかを更新し続ける契約なのだ。

## AI戦争で、敵と取引する

米中の競争は、いま半導体とAIへ集まっている。

高性能チップ、製造装置、データセンター、電力、研究者、通信網。AIは画面の中だけにある技術ではない。鉱物を掘り、膨大な電気と水を使い、工場と海底ケーブルを通り、軍事の情報処理や無人システムにも接続する物質的な体系である。

米国は先端半導体と製造装置を国家安全保障の問題として扱い、輸出や輸入を管理する。中国は外部の制限に耐えられる技術生態系を育てようとする。双方が「AIで遅れれば国家が危うい」と語るほど、競争は軍拡の論理へ近づく。軍拡の論理とは、相手が強くなるから、こちらもさらに強くしなければならないという考え方だ。

だがAIには、核兵器とは違う拡散の速さがある。民間企業が開発し、日常のサービスへ入り、モデルや論文が国境を越える。気候予測や医療にも役立つ同じ技術が、監視、標的選定、世論操作にも使われる。

だから米中は、勝とうとしながら、同時に事故を避ける規則を話さなければならない。競争相手との対話は弱さではない。制御を失わないための最低条件である。

## 日本は、誰の側かではなく、何を守るのか

米国か中国か。味方か敵か。その二択だけで世界を見ると、日本はいつも誰かの列の後ろへ並ぶことになる。

たとえば、半導体工場のある町では、水や電力、働く人への負担も関わる。国同士の勝ち負けだけでは、その生活が後ろへ退いてしまう。

AIを、人を監視し選別する技術ではなく、暮らしと知を支える技術にできるか。半導体の安全保障を語るとき、工場の水、電力、労働、地域の負担まで見られるか。台湾海峡の緊張を語るとき、勇ましい言葉が最初に危険へさらす生活を想像できるか。

外交の目的は、首相が赤絨毯を歩くことではない。その国で暮らす人々が、戦争や経済的な威圧に脅かされず、他国の人々の尊厳も奪わずに生きられる条件をつくることだ。

赤絨毯は、確かに地図になる。けれど、それが描くのは友情の地図ではない。誰を必要とし、誰を当然視し、誰を恐れ、誰と取引せざるをえないのかという、移り続ける力の地図である。

その地図の端で日本がすべきことは、もっと大きな歓迎をねだることではない。

自分の足で立ち、何を守る国なのかを、自分の言葉で言えるようになることだ。
