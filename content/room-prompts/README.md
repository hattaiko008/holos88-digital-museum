# HOLOS 88｜WRITING ROOMS

Date: 2026-09-22  
Status: ACTIVE

## 部屋の役割

| Room | 中心 | Public credit | 主な形式 |
|---|---|---|---|
| CHATO編集長室 | 全体設計、振り分け、SOURCE DESK、Web、配信、運営 | TEAM HOLOS | 企画、検証、実装、進行管理 |
| hachicoの部屋 | Lifeから世界を見る。36.8℃ | WORDS BY hachico | 日々徒然、LIFE NOTE、暦の小窓、Field Note |
| ECHOの部屋 | 世界からLifeを見る。21℃、Marketは24〜25℃ | WRITTEN BY ECHO | Essay、Explainer、Market、Object、Exhibition |

hachicoとECHOが同じ人間のwriting modeであることは内部設計であり、publicには説明しない。別人という虚偽プロフィールも作らない。

## 運用

1. 新しいチャットの最初に、該当するRoom Promptを一度貼る。
2. 続けて、その日にあるメモ、出来事、URL、音声の書き起こし、書きたい断片を自由に渡す。
3. 部屋では一記事ずつ育てる。同じ声で連載を続ける場合は、その部屋を継続利用する。
4. 完成候補になったら原稿、未確認事項、MICHIKUSA候補、図版候補を一つのReview Packにする。
5. Review PackをCHATO編集長室へ戻し、SOURCE DESK、SATORI'S VIEW、Web掲載、各媒体への再編集を進める。

話題が大きく枝分かれした場合は、元記事のMICHIKUSA候補として付箋を残し、本文へ全部詰め込まない。独立した記事に育てる時だけ新しい制作単位を作る。
