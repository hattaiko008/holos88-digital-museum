## Series distinction

### A｜hachicoの日々徒然

その日に起きたこと、家のこと、雨、コハク、買い物、身体の小さな変化。予定調和のない日記型のLIFE NOTE。季節を扱っても、暦を説明することが目的ではない。

### B｜暦の小窓（working title）

二十四節気と七十二候を定点にして、空、月、星、古い習慣、食、暮らし、身体感覚、土地の記憶へ道草する連載。hachicoのフランクなリズムで書くが、日記より少しだけ編集された「季節の観察記」にする。

候補名：`暦の小窓` / `季節の道草` / `七十二候の手帖` / `めぐる日のノート`。公開名はサンプルを書いてから決める。

## Voice

- hachicoの36.8℃。柔らかな標準語に、会話やツッコミとして関西弁を少量。
- 2〜4文の段落を基本にする。ポエム化しすぎず、最後に生活へ戻る。
- 「養生」「運気」「魔女的」「シャーマニック」は、文化・象徴・個人の感じ方として扱う。医学的効果、占いの予言、霊的な因果を保証しない。
- 古い慣わしは、いつ・どこで・誰の記録かを確認する。日本全国の普遍的伝統として平板化しない。
- 科学的な天体・気候・生理の記述と、伝承・解釈・hachicoの感覚を本文上で混ぜない。

## Observation card

各回の下書きに次の欄を置く。毎回すべてを埋める必要はない。

```text
DATE / PLACE
SEKKI / KŌ
WEATHER / SKY / MOON
BODY OR LIFE NOTE
OLD CUSTOM / WORD / OBJECT
FOOD OR SMALL PRACTICE
SYMBOLIC WINDOW
ONE QUESTION
ONE MICHIKUSA
SOURCES / RIGHTS
```

七十二候を毎回記事化する義務は置かない。最初は月1〜2本、季節の節目で続け、実際の観察が追いつく頻度を優先する。

## Article movement

`SEASONAL OBJECT → FIELD NOTE → OLD WINDOW → BODY / LIFE → SYMBOLIC WINDOW → RETURN`

例：秋分の日の光 → 庭の影 → 昔の彼岸の記録 → 眠りや食卓の小さな工夫 → 月と境目の象徴 → 明日の生活へ戻る。

機械的な「関連リンク欄」を本文の途中に挿入しない。hachico自身がMICHIKUSAなので、必要なときだけ記事末尾に一つの入口を置く。

## Reference note: starnet

「ハチの里山日記」の本文を、公開ウェブ上でそのまま確認できる状態には戻せなかった。検索で確認できたのは、旧starnetのブログに残る季節の暮らし・農・植物の記事断片と、現在のstarnetが掲げる「身体とは、いちばん身近にある自然」という考え方である。

## Editorial / source desk

各回で次の層を分ける。

```text
CALENDAR / ASTRONOMY — verified fact
CUSTOM / HISTORY — source and region
FIELD OBSERVATION — hachico's experience
SYMBOL / WITCH WINDOW — interpretation
LIFE PRACTICE — modest, non-medical suggestion
OPEN QUESTION — reader's next window
```

図版は古い暦、植物図譜、星図、料理・道具の資料などを候補にする。公開時は作者、年代、所蔵館、権利状態、出典URLをSOURCE DESKで確認する。
