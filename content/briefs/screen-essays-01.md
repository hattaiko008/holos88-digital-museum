# HOLOS 88｜SCREEN ESSAYS 01

## 記事が、映像の時間を持つ。

**VIDEO FORMAT BRIEF / WORKING TITLE**  
Status: concept and production protocol — public title not fixed

## 1｜二つの番組を混ぜない

### hachico｜閑話休題

暮らしから始まる。会話、観察、寄り道、笑い、その日の体温。hachicoがその時に見ている世界へ、自由に歩いていく番組。

### ECHO｜HOLOS SCREEN ESSAYS（仮）

一つの標本から始まる。資料、図版、地図、環境音、字幕、静かなナレーションを使い、記事を別の時間のかたちへ移す。説明動画でも、ニュース解説でも、朗読動画でもない。

```text
ARTICLE = 読む旅
SCREEN ESSAY = 見る時間
```

両者の関係をpublicに説明しない。クレジットは記事と同様に、`WRITTEN BY ECHO`、`VISUAL RESEARCH — TEAM HOLOS` などを用いる。

## 2｜一本の基本構成

標準尺は **6〜10分**。短くしすぎず、情報を詰め込みすぎない。

```text
00:00  OBJECT
       種、蹄、地図、月、麦の穂、二つの金利など。

00:20  QUESTION
       「これは、何と何につながっているのだろう。」

01:00  OBSERVE
       記事の核となる事実と、その資料。

03:00  CONNECT
       図版、地図、写真、文書、音で関係を一つずつ開く。

06:30  MICHIKUSA
       次の展示室へ通じる、ひとつの強い小窓。

08:00  RETURN
       最初の標本へ戻る。答えで閉じず、見え方を少し変える。

08:30  SOURCE WINDOW
       使った資料、画像の権利、更新日を静かに示す。
```

記事の段落をそのまま音読しない。映像に必要な沈黙、呼吸、資料を見る時間を残す。文章が説明しすぎる場所は削り、画面が説明できない場所だけを言葉にする。

## 3｜映像の言葉

- 古い木版画、自然史図版、地図、古文書、写真、標本、手、風景、環境音。
- 原本のHOLOSロゴを中心に置く場合、再生成・描き直し・ベクター化をしない。
- 歴史資料をAI画像で捏造しない。現存しない事件・人物・文書を「資料風」に作らない。
- AIは、字幕、編集補助、資料整理、図の構成に使えても、史実の代替にしない。
- 音楽で感情を指示しない。環境音か、意味のある音だけを使う。自動再生はしない。
- 字幕は日本語を基本にし、必要な英語は資料名や小さな補助に留める。
- 色は番組側で固定しない。収蔵資料と世界が持ってくる色を使う。

## 4｜最初の5本

### 01｜SEED

黒い粒、発芽図、種袋、土。  
問い：蒔けば生えるわけでもないのに、なぜ私たちは種を未来の比喩にするのか。

### 02｜HORSE

蹄、骨格、装蹄図、草原、古い地図。  
問い：馬は人を遠くへ運んだ。では、人は馬をどんな世界へ運んだのか。

### 03｜MOON TO STARS

月齢図、秋の四辺形、野尻抱影の資料棚、古い星図。  
問い：空を見上げるとき、人は何を時間として読んできたのか。

### 04｜MILLET / LAND

麦、落穂、畑の境界、絵画資料、地籍図。  
問い：畑は、誰のものだったのだろう。

### 05｜8:45 WINDOW

日銀・FRBの公表文書、二つの数字、海峡、港、食卓。  
問い：市場の別々の数字は、どこで同じ財布に出会うのか。

市場・政治・紛争を扱う回は、収録日とSOURCE DESK確認日を画面と概要欄に必ず示す。

## 5｜記事から映像への制作カード

各回に、次の情報を一枚で持つ。

```text
ARTICLE ID
VIDEO QUESTION
OPENING OBJECT
FACTS THAT MUST BE CURRENT
SOURCE MATERIALS
VISUAL RIGHTS STATUS
NARRATION DRAFT
SILENCE / ENVIRONMENTAL SOUND
ONE MICHIKUSA
RETURN IMAGE
SATORI'S VIEW (optional)
PUBLISHING DATE
SOURCE DESK CHECK DATE
```

SATORI'S VIEWを動画の結論にしない。使う場合は、最後の映像が終わりかける場所に、一行だけ置く。

## 6｜YouTubeの役割

YouTubeは、HOLOSの入口の一つ。全文を置き換える場所ではない。

```text
VIDEO
  ↓
ARTICLE / SOURCE WINDOW
  ↓
MICHIKUSA
  ↓
COLLECTION / PLACE / RELATIONSHIP
```

概要欄には、記事リンク、主要資料、画像権利、訂正・更新日を置く。アフィリエイトや販売導線は、映像の意味を壊さないものだけを後から検討する。

## 7｜最初の運用

1. 記事を完成させる。
2. SOURCE DESKと画像権利を確認する。
3. SATORI'S VIEWを受け取る。
4. 6〜10分のナレーション草稿とショットリストをつくる。
5. 1本だけ試作し、文字量、沈黙、字幕、音、資料の見やすさを確認する。
6. 型を整えてから、月1〜2本のペースで育てる。

大量投稿を目的にしない。一回の映像が、Museumへ入る価値のある扉になるかで決める。
