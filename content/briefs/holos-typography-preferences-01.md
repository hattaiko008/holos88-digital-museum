# HOLOS 88 — typography preferences

Recorded: 2026-09-27

## Strong preference

### Core Latin family

**Cormorant Garamond**

- Light / Regular：大きな見出し、章扉、知的で静かな導入
- Italic：SHE CREATES、問い、余韻のある短い見出し
- hachicoが特に好んだ見本：
  - “Large letters, different voices.” — Cormorant Garamond Light / Regular
  - “How to choose.” — Cormorant Garamond Light Italic
- 細い線、字形の揺らぎ、RegularとItalicの行き来を好む。
- SHE CREATESの主見出しは **L-01 / Cormorant Garamond Italic** でよい。

### Supporting choices currently favored

- L-05 / Petit Formal Script：短い筆記体。1〜5語程度に限定。
- J-03 / Klee One：柔らかな日本語見出し。長文本文には使わない。
- J-01 / Shippori Mincho：日本語本文。
- J-08 / Zen Kaku Gothic New：図版キャプション、資料番号、小さな情報。
- L-02 / Bodoni Moda：号数、暦、大数字の候補。Cormorantとの比較で使用。

## Avoid / very unlikely to use

カタログから削除はしないが、通常の提案候補から外す。

- **J-04 / Kaisei Decol**
- **J-05 / Yuji Syuku**
- **J-07 / Zen Kurenaido**

## Working rule

新しいデザインでは、まず Cormorant Garamond Light / Regular / Italic の中で解決できるかを検討する。筆記体を追加する前に、CormorantのItalicで十分な女性性と手の気配が出ないか確認する。女性性は甘さや装飾量ではなく、細い線、曲線、余白、静かな強さで表す。
