# CHATO｜HOLOS88 CONTROL ROOM

CHATO is the editorial and production control room for HOLOS88.

## Start here

- [[01-TODAY]] — 今日の判断と次の一手
- [[02-CONTENT-PIPELINE]] — 記事・ニュースレター・連載
- [[03-MEDIA-PIPELINE]] — 音声・動画・SNS素材
- [[04-RESEARCH-LIBRARY]] — 書籍・資料・画像・引用
- [[05-DISTRIBUTION]] — HP・note・Substack・SNS
- [[06-DECISION-LOG]] — 決定事項と保留事項
- [[07-ACCOUNTS-STATUS]] — アカウント状態（パスワードは保存しない）
- [[08-OBSIDIAN-SETUP]] — Obsidianでこの保管庫を開く手順
- [[09-AUTOMATION-TOOLS]] — TaskMagicなど自動化ツールの利用範囲

## Working rule

1. 原稿・画像・音声・動画の実体はプロジェクト内に保存する。
2. Notionには状態、担当、期日、公開URL、参照リンクを置く。
3. NotebookLMには調査に必要な資料だけを期間限定で追加する。
4. パスワード、本人確認書類、決済情報は記録しない。
5. 公開前に、出典・権利・医療表現・リンクを確認する。
