# Obsidian setup

Obsidianはアカウント登録なしで使える。HOLOS88では、この `CHATO-HQ` フォルダをローカル保管庫として開く。

## 最初の一回

1. Obsidianアプリをインストールする。
2. 「Open folder as vault（フォルダを保管庫として開く）」を選ぶ。
3. `HOLOS88-DIGITAL-MUSEUM/CHATO-HQ` を指定する。
4. 最初に `README.md` と `01-TODAY.md` を開く。

## 運用

- 今日の判断と次の作業は `01-TODAY.md` に置く。
- 記事、音声、動画の進行は各パイプラインに記録する。
- 調査資料は出典、権利、保存先を `04-RESEARCH-LIBRARY.md` に残す。
- 決定事項は `06-DECISION-LOG.md` に日付付きで残す。
- パスワード、認証コード、本人確認書類、銀行・決済情報は保存しない。

## アカウントが必要になる場合

Obsidian Syncなどの有料クラウド機能を使う場合のみ、Obsidianアカウントを作る。まずはローカル運用で十分。
