PAGE ROLEこのページの役割

初めてHOLOS 88を訪れた人が抱く、

> このサイトは、なんなんだ？ > > なぜ、種の次に哲学があり、馬の向こうに経済があり、縄文からAIへ行けるのだろう。

WHAT IS THIS PLACE?

ここは、何を集めている場所なのか

種の話を読んでいたはずが、いつの間にか絵画へ出る。

時間について考えていたら、江戸の時計が現れる。馬の足跡を追えば、戦争、農業、競馬、ケア、進化へ道が分かれていく。縄文土器の前に立っていた岡本太郎から、パリの民族学者へ戻り、その机に置かれたカードからAIの話が始まる。

少し、とっ散らかって見えるかもしれない。

それで合っています。

世界はもともと、博物館の展示室のように、きれいな分野別にはできていないからです。

食べることは、身体の話であり、土地の話であり、気候、労働、政治、記憶の話でもある。一つの物のなかに、いくつもの時間と関係が折り重なっています。

HOLOS 88が集めているのは、世界にある「もの」だけではありません。

ものと、もののあいだにある関係です。

ここは、世界がつながっていることを収蔵するMuseumです。

そして、ここで何かを成し遂げなくても構いません。

できなくてもいい。変わっていなくてもいい。頑張れない日があってもいい。

窓の前で立ち止まった時間も、何も書かなかった時間も、なくなりません。

私たちは、生きている。

BETWEEN THE WINDOWS

見えるものより、あいだにあるもの

一つの記事は、一つの窓です。

窓からは、種が見える。月が見える。市場が見える。古い土器、犬や猫、雨、戦争、哲学者、台所の生ごみ処理機まで見えることがあります。

けれど、HOLOS 88の本体は、窓そのものだけではありません。

種と絵画のあいだ。

贈り物と社会保障のあいだ。

縄文土器と太陽の塔のあいだ。

カード箱とAIのあいだ。

遠く離れて見えた二つの窓の間に、一本の道が見えたとき、世界の見え方が少し変わります。

私たちは、その道を RELATIONSHIP と呼びます。

BETWEEN THE WINDOWS.

窓と窓のあいだに、まだ名前のない世界があります。

A MUSEUM OF RELATIONSHIPS

分けるための分類、戻るための関係

Museumには分類があります。

植物、動物、宇宙、身体、哲学、歴史、政治、経済、民俗、工芸、食、土地、技術。分類は、広いMuseumで入口を見つけるために必要です。

ただし、一つの記事を一つの箱へ閉じ込めるためではありません。

カテゴリーは入口。

Relationshipは通路。

記事はJourney。

CollectionはArchive。

分類によって見つけ、関係によって境界を越え、最後は自分のLifeへ戻ってくる。

そのためのMuseumです。

HOW TO WALK

正しい順路は、ありません

最初から全部を理解する必要はありません。

気になる言葉を一つ選んでください。美しい図版でも、知らない名前でも、「なんやそれ」という違和感でもかまいません。

一つの記事を読み終えると、別の窓へ続く小さな道が残されています。

  • READ — 一つの物語を読む
  • MICHIKUSA — 横道へ入る
  • CONNECT — 離れたものの関係を見つける
  • RETURN — 自分の暮らしへ戻る
  • SEE AGAIN — 昨日までの世界を、もう一度見る

すべてのリンクを開く必要はありません。

途中で閉じてもいい。翌日に戻ってもいい。まったく別の入口から入り直してもいい。

ここでは、迷ったことも閲覧履歴です。

MICHIKUSA IS THE METHOD

道草は、余談ではない

最短距離なら、検索すれば答えは見つかります。

けれど、答えと答えのあいだにあるものは、検索結果の一番上に出てくるとは限りません。

知らない植物の名前から、土地の食文化へ行く。古い絵の片隅から、当時の労働へ入る。市場の数字から、同じ日の食卓を見る。

目的地へ急がず、途中で見つけたものに立ち止まる。

MICHIKUSAは、HOLOS 88の余談欄ではありません。

世界を探索するための方法です。

AIには最短距離を。

人間には道草を。

その時間をLifeへ還す。

そして、どの道を選ぶかは、人間に残します。

AN EXPERIMENT IN THE CHAIN OF KNOWING

知恵の連鎖を、観察する

この記事群は、最初から完成した百科事典を目指していません。

一つの問いが、次の問いを生む。

誰かの研究が、別の時代の暮らしへ届く。古い道具が、現在の技術を考え直させる。読者の小さな違和感が、まだ存在しない記事の種になる。

知識は、棚に置いた瞬間に完成するのでしょうか。

それとも、誰かが受け取り、自分の経験と結び、別の誰かへ渡したとき、もう一度生まれるのでしょうか。

HOLOS 88は、知識を所有する場所というより、知恵が姿を変えながら渡っていく過程を観察する実験です。

事実は、できる限り確かめます。

解釈は、解釈として置きます。

分からないことは、分からないまま窓を開けておきます。

Museumは完成品ではなく、関係が育ち続ける場所です。

WHO IS SPEAKING?

いくつかの声、同じMuseum

HOLOS 88には、いくつかの声があります。

hachicoは、Lifeから世界を見ます。

雨、犬や猫、台所、散歩、季節。暮らしの足元から、世界へ道草します。

ECHOは、世界からLifeを見ます。

歴史、科学、哲学、社会、市場。少し離れた窓から眺め、最後に私たちの暮らしへ戻ってきます。

TEAM HOLOSは、資料を探し、事実を確かめ、関係を編み、Museumの道を整えます。

声の温度は違っても、目指す場所は同じです。

世界を、ばらばらのままにしないこと。

THE BATON

次の窓は、あなたのところにある

ここにある関係が、唯一の答えではありません。

同じ土器を見ても、思い出すものは人によって違う。同じ記事を読んでも、次に開きたくなる窓は違います。

あなたの記憶。

今日見たニュース。

祖母が使っていた道具。

散歩道に落ちていた種。

ずっと意味が分からなかった言葉。

それらが、ここにある何かとつながったなら、その瞬間から次のJourneyが始まります。

私たちは、窓を開けます。

道を一本だけ示します。

その先を歩くのは、あなたです。

そして、もし新しい関係を見つけたら。

次は、あなたが誰かへ渡してください。

THE NEXT WINDOW IS YOURS.

次の窓を、あなたへ。

UI / COMPOSITION NOTES

画面構成案

余白の大きな白い画面。大きく `BETWEEN THE WINDOWS`。日本語は小さく「窓と窓のあいだに」。二つの細い窓枠の間を、一本の線だけが横切る。

  • OPENING

種、月、馬、土器、カードなど、既存記事の図版の一部が離れて配置される。スクロールすると細い線で一時的につながる。

  • WHAT IS THIS PLACE?

`CATEGORY = ENTRANCE / RELATIONSHIP = PATH / ARTICLE = JOURNEY / COLLECTION = ARCHIVE` を、カードではなく誌面のような大胆なタイポグラフィで見せる。

  • RELATIONSHIP

`READ → MICHIKUSA → CONNECT → RETURN → SEE AGAIN`。横一列の工程図にはせず、ページを歩くにつれて言葉が現れる。

  • HOW TO WALK

一つのObjectから複数の窓へ広がる小さなRelationship Map。操作は任意。動きは遅く、reduced motionでは静止図版になる。

  • KNOWING EXPERIMENT

最後は図版を減らし、文章だけへ戻る。`THE NEXT WINDOW IS YOURS.` の下に、記事探索へ戻る入口を三つだけ置く。

  • THE BATON

最後の三つの入口

  • FOLLOW A WORD — 言葉から歩く
  • FOLLOW AN OBJECT — ものから歩く
  • WANDER — Museumに任せる

表記上の判断

  • 正式英語表記は BETWEEN THE WINDOWS。
  • ナビゲーションでは長いため、`BETWEEN` または `ABOUT` を検討。
  • 「知恵の連鎖の実験」は本文内の説明語として使い、サイト全体の硬い標語にはしない。
  • 読者投稿機能は公開初期には設けず、「あなたへのバトン」は思想と体験として表現する。将来、見つけた関係を送れる仕組みへ発展可能。
