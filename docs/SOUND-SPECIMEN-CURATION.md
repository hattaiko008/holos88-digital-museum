# SOUND SPECIMEN — CURATION NOTE

## Purpose

HOLOS 88は、場所を地図や文章だけでなく、音でも収蔵する。
雨、風、馬の息、鳥、水、道具、市場、森、台所などを、場所・時刻・季節・関係とともに記録する。

## Sound Bum

Sound Bumは「音を借りる素材庫」ではなく、世界へ耳を向ける方法を教えてくれる先行プロジェクトとして扱う。活動と思想を紹介する記事を作り、公式ページへ導く。既存のCD、試聴音源、公開録音は、Web再配信の明示的な許諾が確認できるまでHOLOS内で複製・配信しない。

将来は、権利者へ少数音源の紹介許諾または共同企画を相談できる。

## Public rules

- autoplayしない。
- 録音者、場所、日付、公開元、利用条件を記録する。
- 自主録音、明確なCC0／CC BY音源、公式に公開されたストリームを優先する。
- CC BYは指定クレジットを表示する。
- 人の会話、私有地、儀礼、希少生物の位置などは、権利と倫理を別々に確認する。
- generic AI BGMは使わない。

## Time Atlas prototype

- LISTENは公式公開ストリームをHOLOS内の再生装置で聴く。
- OLD MAPSはPublic Domain／Open Access資料を同じ画面に表示する。
- 外部サイトは原典確認のSOURCE DESKとして残し、閲覧体験の中心にはしない。
